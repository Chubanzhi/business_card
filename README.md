# 汽车4S店名片微信小程序

## 项目简介
一款专为汽车4S店设计的微信小程序，用于展示店铺信息、联系方式、服务项目等，方便客户快速了解店铺并联系。

## 功能大纲

### 1. 核心功能模块

#### 1.1 店铺信息展示
- 店铺名称、Logo展示
- 店铺简介
- 营业时间
- 店铺地址（支持地图导航）
- 店铺实景照片轮播

#### 1.2 联系方式
- 一键拨打电话
- 一键复制微信号
- 一键添加微信好友
- 在线客服咨询

#### 1.3 服务项目展示
- 新车销售
- 二手车置换
- 维修保养
- 保险服务
- 金融贷款
- 其他增值服务

#### 1.4 车型展示
- 热门车型推荐
- 车型详情（图片、价格、配置）
- 预约试驾功能

#### 1.5 优惠活动
- 最新优惠活动展示
- 促销信息
- 会员权益

#### 1.6 在线预约
- 预约试驾
- 预约保养
- 预约维修
- 预约咨询

#### 1.7 个人中心
- 我的预约记录
- 收藏的车型
- 优惠券管理
- 个人信息设置

### 2. 技术架构

#### 2.1 前端技术栈
- 微信小程序原生框架
- 微信小程序UI组件库（如：Vant Weapp / WeUI）
- 微信小程序地图API
- 微信小程序客服消息API

#### 2.2 后端技术栈（可选）
- Node.js / Python / Java
- 数据库：MySQL / MongoDB
- 云服务：微信云开发 / 自建服务器

#### 2.3 第三方服务
- 微信支付（可选）
- 地图服务（腾讯地图）
- 图片存储（OSS / 微信云存储）

### 3. 页面结构

```
pages/

```

### 5. 设计规范

#### 5.1 色彩方案
- 主色调：汽车行业常用蓝色/红色
- 辅助色：灰色系
- 强调色：金色/橙色（用于优惠信息）

#### 5.2 字体规范
- 标题：32rpx-36rpx
- 正文：28rpx-30rpx
- 辅助文字：24rpx-26rpx

#### 5.3 间距规范
- 页面边距：30rpx
- 组件间距：20rpx-30rpx

### 6. 数据需求

#### 6.1 店铺数据
- 店铺基本信息
- 联系方式
- 营业时间
- 地址坐标

#### 6.2 车型数据
- 车型图片
- 车型名称、价格
- 车型配置信息

#### 6.3 服务数据
- 服务项目列表
- 服务价格
- 服务说明

### 7. 开发注意事项

- 遵循微信小程序开发规范
- 注意小程序包大小限制（主包2MB，分包20MB）
- 优化图片资源，使用WebP格式
- 做好错误处理和用户提示
- 考虑不同屏幕尺寸适配
- 做好数据缓存，提升用户体验
