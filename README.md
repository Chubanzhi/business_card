# 亿车乐 - 汽车经销名片小程序

## 项目简介

一款专为汽车4S店设计的微信小程序，分为C端（客户端）和B端（员工端）两个核心端，实现名片展示、线索管理、营销工具、售后服务等完整功能。

## 系统架构概述

本系统分为两个核心端：

- **C端（客户端）**：承载名片展示、车型浏览、活动报名、售后服务及裂变分享
- **B端（员工端）**：承载名片信息维护、线索管理（CRM）、客户跟进记录及交车工具

## 功能模块

### C端功能

#### 1. 名片展示
- 员工名片信息展示（头像、姓名、门店、电话、微信、从业年限）
- 个人标签和服务亮点展示
- 个人格言和荣誉展示
- 一键拨打电话、复制微信号

#### 2. 车型浏览
- 车型列表展示
- 车型详情页
- 预约试驾功能
- 一键询价（触发留资弹窗）

#### 3. 服务项目
- 新车销售
- 维修保养
- 二手车置换
- 保险服务
- 金融贷款
- 其他增值服务

#### 4. 营销工具
- **转介绍有礼物（MGM裂变）**
  - 老客户生成专属海报/链接
  - 新客户扫码留资
  - 双方关联，核销发奖
  - 专属邀请码和二维码
  
- **二手车/包销车/特卖**
  - 特价车型列表
  - 库存车、特价、厂家包销标签
  - 预约看车功能
  
- **到店有礼物**
  - 提前登记到店时间
  - 到店签到
  - 领取礼品

#### 5. 售后与车主服务
- **联系售后服务**
  - 售后热线、道路救援热线（一键拨打）
  - 绑定专属售后顾问名片
  - 在线留言/投诉
  
- **成交照片**
  - 交车现场照片上传
  - 照片墙/轮播图展示
  - 授权门店宣传使用
  
- **精诚一家保养 & 权益**
  - 保养套餐展示和预约
  - 权益政策展示
  - 转发给客户功能

#### 6. 留资/询价
- 通用弹窗组件
- 表单字段：姓名、联系电话、意向车型、预算范围、计划购车时间
- 微信一键获取手机号
- 提交后数据推送到B端线索看板

### B端功能

#### 1. 员工登录
- 手机号 + 短信验证码登录
- 员工白名单验证
- 非授权员工提示

#### 2. 员工工作台
- 状态栏显示登录状态
- 名片预览区（展示C端效果）
- 核心入口：进入信息管理、线索管理
- 退出登录功能

#### 3. 员工信息配置
- 头像上传/裁剪
- 基础信息：姓名、手机号、微信号
- 职位信息：所属品牌、所属门店、职位、从业年限
- 标签管理：个人标签、服务亮点
- 个性化文案：个人格言、个人荣誉
- 实时更新C端名片展示

#### 4. 线索管理系统（CRM）
- **线索看板**
  - 按时间倒序展示潜客线索
  - 卡片信息：客户称呼、来源标签、意向标签、时效性
  - 一键呼叫功能
  
- **线索跟踪详情页**
  - 客户画像展示
  - 跟进记录流（Timeline）
  - 写跟进功能
  - 历史记录查看

## 数据埋点需求

为了衡量名片效果，需要开发以下数据统计点：

1. **获客来源统计**
   - 自然流量
   - 朋友圈海报识别
   - 微信好友转发

2. **销售排行数据**
   - 名片被浏览次数（PV/UV）
   - 名片被保存/转发次数
   - 通过名片获取的线索数量（电话拨打数、表单提交数）

3. **内容热度**
   - 哪款车型查看人数最多
   - 哪个活动报名人数最多

## 设计规范

### 色彩方案
- 主色调：蓝色系（#3b82f6）
- 渐变：蓝色渐变（#2563eb → #60a5fa）
- 背景色：浅灰色（#f3f4f6）
- 卡片背景：白色（#ffffff）

### 字体规范
- 标题：32rpx-48rpx
- 正文：28rpx-30rpx
- 辅助文字：24rpx-26rpx

### 间距规范
- 页面边距：32rpx
- 组件间距：24rpx-32rpx
- 卡片圆角：32rpx

## 开发注意事项

- 遵循微信小程序开发规范
- 注意小程序包大小限制（主包2MB，分包20MB）
- 优化图片资源，使用WebP格式
- 做好错误处理和用户提示
- 考虑不同屏幕尺寸适配
- 做好数据缓存，提升用户体验
- B端功能需要员工白名单验证
- 线索数据需要实时同步到后台
